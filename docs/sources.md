# Sources

The [source registry](https://github.com/sayanmohsin/nice-code/blob/main/sources/index.md) records the public references used by Nice Code patterns.

The registry covers guidance from Microsoft, Google, React, Vercel, Airbnb, Go, Dart, AWS, MDN, and Cloudflare where directly relevant. Each adopted principle records its organization, URL, section, applicable technologies, and review date.

Review sources periodically. A link alone is not evidence that a local check is correct; each pattern explains how guidance was adapted and enforced.
