# Pattern catalog

Patterns are the review vocabulary used by Nice Code. The canonical documents live in the repository’s [`patterns/`](https://github.com/sayanmohsin/nice-code/tree/main/patterns) directory.

Current groups include logging and observability; conditions, control flow, async, and concurrency; error handling and API boundaries; state, persistence, and data integrity; testing and verification; security and privacy; performance measurement; web and UI behavior; code review; and AI-generated code failure modes.

Each document records the problem, recommended pattern, weak examples, enforcement level, exceptions, and public sources.
