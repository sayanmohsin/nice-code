# Pattern catalog

Patterns are the review vocabulary used by Nice Code. Each document explains the problem, recommendation, examples, enforcement level, exceptions, and public sources. Some checks are automated; others call for engineering judgment.

## Logging and observability

- [Logging and observability](https://github.com/sayanmohsin/nice-code/blob/main/patterns/logging-and-observability.md): structured events, useful context, and redaction.
- [Java logging and coding standards](https://github.com/sayanmohsin/nice-code/blob/main/patterns/java-logging-and-coding-standards.md): logging practices and language-specific guidance.

## Async and concurrency

- [Async and concurrency](https://github.com/sayanmohsin/nice-code/blob/main/patterns/async-and-concurrency.md): dependencies, bounded parallelism, and failure handling.
- [Reliability and operations](https://github.com/sayanmohsin/nice-code/blob/main/patterns/reliability-and-operations.md): timeouts, retries, cancellation, and operational behavior.

## Security and data integrity

- [Security and secrets](https://github.com/sayanmohsin/nice-code/blob/main/patterns/security-and-secrets.md): credentials, authorization, validation, and trust boundaries.
- [Persistence and data integrity](https://github.com/sayanmohsin/nice-code/blob/main/patterns/persistence-and-data-integrity.md): transactions, constraints, and durable state.

## More patterns

The [complete pattern index](https://github.com/sayanmohsin/nice-code/blob/main/patterns/index.md) also covers control flow, error handling, API boundaries, state, testing, performance measurement, React and UI behavior, Java and Spring Boot, code review, and AI-generated changes.
