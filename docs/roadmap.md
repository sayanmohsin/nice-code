# Roadmap

Near-term work is deliberately practical: improve signal quality from representative projects; keep agent output compact and stable; expand baseline and monthly audit reporting; validate the Rust engine and transparent Node-compatible launcher; harden GitHub Release binaries, checksums, and automated npm publishing; and add framework-aware checks only when a recurring gap is demonstrated.

Nice Code should stay dependency-light, conservative, and easy to remove from a project. New checks must earn their place through useful evidence. Versioned binaries and the scoped npm package are built and published through GitHub Actions.
