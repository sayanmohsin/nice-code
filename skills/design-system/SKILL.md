# Design System Foundations

Use this skill when starting or redesigning a user interface. First inspect
the existing product language, component primitives, tokens, and responsive
behavior. Preserve intentional identity; do not replace an existing interface
with generic gradients, arbitrary spacing, or a second component library.

Keep product-specific choices in the repository's `DESIGN.md`. Treat visual
quality, hierarchy, motion, and responsive behavior as review work that needs
rendered feedback in addition to source analysis.
