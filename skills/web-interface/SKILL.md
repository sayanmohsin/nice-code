# Web Interface Quality

Use this skill when creating or reviewing web interfaces. Preserve the
project's design direction and component primitives while checking semantic
HTML, keyboard operation, visible focus, accessible names, resilient loading,
empty and error states, responsive layouts, reduced motion, and layout-shift
prevention.

This is guidance for agents and reviewers. It does not prove visual quality
from source inspection alone. Use the project's `DESIGN.md` and rendered
browser checks for product-specific and visual decisions.

Source: https://vercel.com/design/guidelines
